AI 공부 플래너

학습 데이터를 기반으로 개인 맞춤형 공부 전략을 제공하는 웹 시스템

프로젝트 개요

AI 공부 플래너는 사용자의 목표, 과목 정보, 공부 기록을 저장하고 분석하여 개인에게 맞는 학습 방향과 코칭을 제공하는 웹 기반 학습 관리 시스템입니다.

학습 목표 설정 → 공부 기록 저장 → 공부 중 질문 → 학습 분석 → 자동 재조정 → 개인화 피드백 → 대시보드 확인

학습 목표, 시험일, 현재 수준, 과목별 난이도와 자신감을 입력합니다.

학습 데이터 저장, Spring Boot REST API, 학습 목표 설정, 공부 기록 저장 및 검증, 학습 데이터 분석, 과목별 분석, 취약 과목 추천, 목표 미달 시 자동 재조정, 공부 중 질문 및 AI 조언, 초기 학습 코칭, 개인화 종합 피드백, 대시보드 출력 기능을 구현했습니다.
